# Transportes e crimes no Rio de janeiro
Uma análise de dados correlacionando os transportes público com suas respectivas áreas junto da criminalidade nessas áreas do rio de janeiro 

Usufruindo de Machine Learning nos dados para estimar a dificuldade de se passar de ônibus em determinadas áreas do rio com alto indice de criminalidade, população elevada e quantidade de pontos em determinados bairros
